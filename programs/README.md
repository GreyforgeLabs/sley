# First-Party Sley Programs

This directory is reserved for small first-party Sley 2 programs and ecosystem
dogfooding that exercise the machine-native program-state model.

Entries must use the active Sley 2 contracts and validation path. Sley 1.x
textual source, compiler extensions, LSP integrations, Tree-sitter grammars,
and compatibility tooling belong in
[`GreyforgeLabs/sley-legacy`](https://github.com/GreyforgeLabs/sley-legacy),
not here.

No example program is implied by this index. Programs should be added only
when they have real content, ownership, and validation evidence.
