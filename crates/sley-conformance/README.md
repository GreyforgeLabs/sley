# sley-conformance

Restricted S20-290 derived execution and test report envelopes. The crate
verifies S20-270 observation evidence, projects stable failures, and compares
S20-240 selected tests without duplicating VM semantics.

These envelopes are in-memory derived evidence. They are not canonical SSMC
report entities, persisted objects, protected-policy decisions, or proof that
a `TestCase` passed. Host/measured metadata is excluded.
