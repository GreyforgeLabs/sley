# Sley 1.x Legacy Lineage

Sley 1.x is complete and frozen at:

<https://github.com/GreyforgeLabs/sley-legacy>

Sley 2 is intentionally incompatible with Sley 1.x. The Sley 1.x textual
syntax, human-readable canonical source, compiler, conventional LSP,
Tree-sitter grammar, CI integration, workbench, conformance tools, learning
material, and audit utilities are historical Sley 1.x components. They are not
native Sley 2 tooling and must not be represented under this repository as
such.

The legacy repository preserves its original tags, releases, license, and
component histories. This repository preserves the independent Sley 2 history,
security policy, repository policy, proprietary license declaration, and
machine-native architecture.
